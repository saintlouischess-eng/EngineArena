# Engine Arena 1.2.1 — refined 3D set

The optional focused board now uses a new sculpted Staunton set with smooth
turned bases and collars, a fully shaped horse head, recessed eyes and nostrils,
a cut bishop mitre, and rounded rook and king details. These are original models
created for Engine Arena; no purchased or downloaded piece assets are required.

Boxwood and ebony finishes use softer grain and broad highlights. Key, fill and
environment lighting keep the dark pieces legible from either side. Softened
cast shadows and contact shadows anchor the pieces on a bevelled wooden board.
Both light and dark application themes use the same piece lighting.

Select **2D / 3D** in Focused game, choose **3D · wooden Staunton**, and apply.
Existing camera, drag, keyboard, flip, zoom and coordinate controls still work.
**Reset camera** restores the standard view. Live game cards keep their 2D boards.

The sculpture asset loads only after 3D is requested. Geometry and the shadow map
are reused. The board redraws on a position, camera, size or display change; it
has no idle animation loop. The shadow map updates only when the piece placement
changes. It uses a single WebGL context and a bounded 1024-pixel shadow map.
Graphics resources are released when returning to 2D. The 2D fallback remains
available if graphics initialization or the WebGL context fails.

Local checks cover all piece meshes, both themes and orientations, a normal
docked board and a laptop viewport, idle rendering, camera interaction, and
context-loss fallback. Screenshots are actual renderer output. These visual
checks use Edge's software WebGL path; performance on every GPU is not claimed.

Close Engine Arena and install `EngineArenaSetup-1.2.1-win-x64.exe` over the
previous version in the same program folder. Existing tournaments and saved
results remain in their separate data folder. This candidate has not been
installed over the owner's application or published to GitHub.

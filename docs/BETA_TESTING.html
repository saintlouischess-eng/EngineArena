Windows 11 x64 · 0.2.0 Beta 1

Welcome to Engine Arena

A workspace for reproducible chess-engine testing, live results and recoverable tournaments.

Your first test

  1. Add two UCI engines. Open Engine library, select your engine executables, test their connections and save the profiles.
  2. Choose a small comparison. Select the profiles, create a tournament, choose your time control and openings, then review the game count and concurrency.
  3. Start and inspect. The tournament is created paused. Choose Start / resume. Watch the focused board and live standings.
  4. Save and reopen. Export a PGN from Results & exports. Close Engine Arena, reopen it and confirm your results are retained.
Everything needed to run the app is included.

Python, .NET and the full offline WebView2 installer come with setup. Add your own chess engines, networks, opening books and tablebases.

Optional CPU temperature and fastest-core readings

Setup includes the signed PawnIO driver installer. It is optional and off by default. Open it from the final setup page, or from Hardware display → CPU sensor setup → Open CPU driver setup. Choose the signed edition and approve Windows permission yourself. Restart Windows if requested.

Then choose Enable CPU readings for this session, select the fields and save. The separate reader needs permission each session; games work without it. Sensor availability depends on your laptop.

Your data stays separate

The program normally lives in %LOCALAPPDATA%\Programs\Engine Arena. Your tournaments, PGNs, profiles and settings normally live in %LOCALAPPDATA%\EngineArena\Data.

Close all Engine Arena windows before an update. Updates and uninstall preserve your tournament data. Shared WebView2 and PawnIO components are retained.

Help improve the beta

Post reproducible problems and suggestions to GitHub Issues. Include the beta version, Windows version, engine versions, time control, opening policy, concurrency, steps and expected versus actual behavior. Review screenshots and PGNs for private details before sharing.

The Engine Arena installer is unsigned. Obtain it from the official repository and keep Windows security protections enabled. Extended unattended testing and broader hardware testing are still pending.

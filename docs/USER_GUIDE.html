Engine Arena 1.2.14

Engine Arena includes Game moves, an optional wooden 3D board, Quick match, Cute Chess/Banksia UCI profile imports and a completion summary. Read the new workflow guide for controls and limitations. Stable release 1.2.14. Designed by Mark Young; coding and implementation by OpenAI Codex. The owner confirmed successful laptop installation and operation.

Version 1.2.14 keeps 3D board letters and rank numbers upright from the current viewing direction, including after rotation and board flip. They remain on the wooden frame and disappear behind nearer pieces instead of overlapping them.

Version 1.2.11 keeps KO results compact. Expand How KO standings work for the complete explanation; it stays open during live updates. Reports retain the full wording. Pairings & tiebreaks now omits the unused Round 1 heading for fixed schedules such as round robin. Actual game rounds remain unchanged.

Version 1.2.10 added a saved Hover help checkbox beside Apply appearance in Display & layout. Turn it off to silence mouse and keyboard control pop-ups. The focused-game header offers Hide 3D controls / Show 3D controls; the same choice appears in 2D / 3D. Hiding the overlay preserves your camera and keeps mouse/keyboard camera controls available. Both choices survive restarting the app.

The 3D board includes vertical framing: use the Height slider, down/up buttons, or the center button beneath Zoom. Shift-drag or Shift+Up/Down also moves the board without changing its viewing angle or zoom. The 2D / 3D dialog accepts a signed vertical position percentage. Positive values raise the board.

Traditional red crown marks identify the original kingside rook and knight of each color. They follow moves, castling and recorded replay; captures remove the mark and promotions do not acquire it. Turn them off in 2D / 3D if preferred. Marks require verified history from the standard initial position. Arbitrary FEN-only openings and nonstandard Chess960 starts remain unmarked; no origins are guessed. The accepted sculptures and wood maps are unchanged.

The focused board retains direct 3D zoom controls. Use the minus/plus buttons or slider, scroll over the board, or focus it and press +/−. Zoom ranges from 60% to 240%. Click the percentage to restore 100%, or press Home to reset the complete camera. The view is saved across restarts and works in docked, floating and expanded windows. The 2D / 3D dialog also accepts a zoom percentage. Select 3D · 1849 Staunton there to enable the wooden set.

Install or update

  1. Copy EngineArenaSetup-1.2.14-win-x64.exe to your Windows 11 x64 laptop.
  2. Close every Engine Arena window, letting saving finish. Run the installer and keep the existing installation folder to upgrade. Saved tournaments, profiles, settings and PGNs are preserved outside the program folder.
  3. Leave Run Microsoft WebView2 setup again unchecked for a normal update. Setup detects an existing runtime and installs its bundled offline runtime when needed. Python and .NET are also included.
  4. Launch Engine Arena from the Start menu. Check the 1.2.14 version in the sidebar. Add your own UCI engines, networks, books and tablebases; these are not included.

The program normally lives in %LOCALAPPDATA%\Programs\Engine Arena; saved data normally lives in %LOCALAPPDATA%\EngineArena\Data. A separate workspace can use EngineArena.exe --data "D:\Arena tests". Open each workspace in one window. Uninstall preserves saved data and shared WebView2/PawnIO components.

Your first comparison

  1. In Engine library, add executables, test connections, and save profiles. Select the profiles to compare. Cloning makes an independently configurable profile, including engine options, Threads, Hash and optional per-engine controls.
  2. Create a New tournament. Review format, scheduled game count, opening source and policy, time control, retry settings, concurrency and CPU/memory/GPU budgets. The number of participants is independent of simultaneous games.
  3. Save the tournament paused. Edit setup… remains available until its first start. Choose Start / resume, or add saved tournaments to the automatic queue.
  4. Review standings, time-forfeit counters, head-to-head, focused game, search history and graphs. Change Concurrent games while running to raise the limit or let excess games finish. Resource budgets still apply.
  5. Use Results & exports for reports and PGNs. Clean games is a concise PGN; Complete archive includes diagnostic and configuration headers. Text exports provide aligned plain text, forum code blocks and Markdown for sharing.

Pause & drain lets active games finish. Stop active games archives unfinished attempts and requeues those games from their recorded openings. Reopening after a crash retains committed results; resume the recovered tournament when ready.

Running several tournaments

Open Tournament manager. Click the Run together card and review shared CPU, memory, game and GPU limits. Individual tournament limits also apply. Assign every GPU engine to gpu0 and use gpu0:1 for one Lc0 instance across this workspace.

Search, filter, sort, start and pause individual entries or selected groups. Options… controls priority and game limits. Reductions let existing games finish. Pause all & drain pauses all tournaments. Live boards can show All running tournaments with names on each card.

Existing queues remain sequential after upgrading; restart requires explicit resume. Budgets apply within one workspace. Linked events and leagues retain ordered stages, and suites and benchmarks wait for the tournament worker to become idle.

Books, clocks and results

The tournament's shared opening book supplies starting positions for both sides. Optional per-profile move books choose moves on each engine's own turns. For engine-plus-book comparisons, clone the engine, assign different profile books, and leave the shared starting position at the initial position. Disable profile books when only the shared tournament opening suite should apply.

Pure nodes sends go nodes N with no chess-clock limit. Startup, readiness and hang watchdogs are separate. Fractional seconds are supported. Per-profile controls override tournament controls, including in handicap comparisons.

W–D–L and points include official games. With color reversal enabled, Elo, confidence intervals and LOS use completed opening pairs. Unpaired tournaments use individual games. LOS is relative to the sampled opposition or selected head-to-head opponent; it is not the probability of winning the tournament. Pool ratings are a separate opponent-adjusted estimate anchored to a reference. Read statistical methods.

To replay a failure, pause and drain, select games in Games & attempt history, then choose Diagnostic replay or Replace official result. Original attempts remain. A replacement changes official statistics once; later Swiss/KO dependencies must be resolved explicitly. Time-forfeit counters retain the original failures.

Workspace and hardware

Display & layout controls theme, font size, board materials, SVG pieces and saved panel layout. Drag, resize, float or hide panels. Boards across sizes live boards to their docked width independently of the number displayed. Board & clocks controls focused-game clock placement and sizing. Language choices include English, Spanish, French, German, Portuguese, Italian, Dutch and Polish.

Hardware display… selects readings and refresh rate. GPU telemetry supports NVIDIA. CPU temperature and live fastest-core readings use the optional signed PawnIO driver and bundled sensor reader. Choose CPU sensor setup, install the signed driver if needed, then Enable CPU readings for this session and approve Windows permission. Enable the reader again after reopening. Games work without it; unsupported sensors show Unavailable.

Worker & recovery controls backup count, interval, storage estimates and optimization. Deleting a tournament removes its records from recovery copies and reclaims managed database space. Export anything you want to keep before deletion.

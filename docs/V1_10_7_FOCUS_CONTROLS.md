# Engine Arena 1.10.7 — More room for the focused board

Click **Hide controls** beside the Focused game heading after setting up your
view. The game picker, watching options, board setup buttons and 3D camera
sliders collapse, giving the board the available space. Click **Show controls**
in the same place to bring everything back.

Engine names, clocks, game status, last move, and the draw counter (if enabled)
remain visible. Float and Expand/Restore remain available. Following an engine,
winning-game watch, sound, final-result holds and camera settings continue as
configured. Hiding controls does not restart or change the game or 3D renderer.

The choice is saved with the workspace and named layouts. It works in docked,
floating and expanded views, with both 2D and 3D boards. Board size remains
limited by the available width and any maximum set under Board & clocks.

Includes all private 1.10.5 and 1.10.6 display, search and watching improvements.
Pause and drain, close Engine Arena, then install the update when ready.

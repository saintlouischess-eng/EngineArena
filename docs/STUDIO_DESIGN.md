# Studio design pass — September 26, 2026

Local development build only. Installer and GitHub publication remain unchanged.

## Design

The shared studio theme uses graphite surfaces, quieter borders, mint action/status
accents, a brass identity mark, consistent line icons, and clearer text hierarchy.
Both dark and light themes share the same geometry. The sidebar follows the
selected theme, including navigation states, icons and worker controls. Tournament selection, run
controls and the queue banner form one group; compact metrics, panel headings and
hardware readings leave more room for the actual results. Tables, dialogs, engine
profiles, events, queue, suites, benchmarks, recovery and storage share the styling.

Appearance has section shortcuts to reach board finishes, colors/text and layouts
without scrolling through every piece design. Live monitoring charts now use their
panel dimensions, readable labels and theme-aware plot colors. Standalone SVG
exports keep their full title and legend independently of the live panel size. Large translated controls wrap
within the dialog. Existing board colors, pieces, clock arrangements, font size,
card-column counts and saved panel sizes remain user preferences.

`ui/studio.css` loads after the feature styles. It does not replace board geometry
or the dock/float model. `ui/studio.js` installs chrome icons once; it adds no
polling, mutation observers or work to live engine updates. There are no downloaded
fonts, background video, animated decorative surfaces or blur filters.

`ui/engine-arena.svg` is original vector artwork. Its seven-size Windows icon is
generated by `scripts/render_brand.cjs` using installed Edge/Playwright and is
embedded in the development executable. The native startup screen uses the same
identity. The generated ICO is committed artwork; ordinary builds need no artwork
toolchain. All artwork is distributed under the project's license.

## Review fixes

- Anchored pool ratings used translated `Csv`/`Json` strings to find DOM IDs. Some
  languages changed their capitalization, breaking the dialog before results and
  export controls were initialized. IDs and wire format names now stay literal.
- A long German custom-piece import label overflowed Appearance at 24px. Labels
  and actions now wrap without expanding the dialog sideways.

## Validation

- `scripts/preview_design.py`: isolated synthetic data and search telemetry; no
  real engine strength claims and no access to the user's database.
- `scripts/validate_design.cjs`: **232** layout checks across seven workspaces,
  twelve dialogs, both themes, 1050/1600/2560px widths, all eight languages at
  24px, all ten tournament format forms, and live-board column sizing with the
  128-board display limit selected (eight synthetic active games). **10** clock
  placement/arrangement checks keep square boards and bounded content.
- `test-output/design-validation.json`: no final layout failures or script/HTTP
  errors. Expected validation responses while switching incompatible draft
  formats are excluded explicitly, not treated as runtime failures.
- `test-output/design-interactions.json`: CSV/JSON export handlers in eight
  languages, Appearance shortcut + save/reload, focus float/dock/keyboard resize,
  tournament report preview and monitoring graph.
- `scripts/validate_graph_design.cjs`: 12 theme/width/font combinations keep
  chart labels at least 10.5 screen pixels; standalone SVG retains its 800x390
  frame, title and series legend.
- **44 JavaScript checks**, **11 focused Python localization/rating tests** passed.
  Existing aiohttp AppKey recommendations remain warnings.
- Native desktop and sensor builds passed. The exact final executable started
  with the embedded icon and local assets and closed normally in a separate empty
  workspace (`test-output/design-native-final.json`).
- Representative screenshots visually reviewed, including dark/light workspaces,
  library, queue, health, Appearance, large German dialogs, focused boards,
  floating window, tournament report preview and graph.

Early preview ratings were blocked by the sandbox's subprocess restriction; the
isolated worker was relaunched with permitted subprocess access. A malformed
column argument in the initial browser harness was corrected before the final
passing run. Neither preliminary failure is counted as a passing check.

This is a presentation pass, not a new endurance or engine-throughput test.
Physical DPI/multiple-monitor behavior and native-speaker translation review
remain part of the broader beta acceptance work.

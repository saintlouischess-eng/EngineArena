# Engine Arena 1.8.3 — Tal 1962 playing set

Private update for owner testing. Designed by Mark Young; coded with OpenAI Codex.

Open **2D / 3D** in Focused Game, or **Appearance…** while using 3D in Player Arena. Select
**3D board**, then **Tal 1962 · Soviet Championship** under **3D piece set**.
The piece choice is shared by both workspaces and saved across restarts.
Camera positions remain independent. Existing 1849 Staunton is still the default.

The approved original sculptures include natural boxwood and ebony, contrasting
king/queen/bishop finials, the thin flat king cross, outward-flared rook crown,
and the rounded knight with a smooth cheek and carved mane. Knight direction
options work with either set. Red kingside crown stamps belong to the 1849 set
only; its saved stamp preference remains available when switching back.

The new model loads on demand and works with the existing boards, lighting,
rooms, captured-piece trays, move animation and photos. Player Arena supports
click and drag input. The live club's distant tables retain their inexpensive
Staunton props. Selecting the new main-board set does not multiply its detailed
meshes across background tables.

Six optimized meshes total 140,000 triangles, including 60,000 for the knight.
The GLB includes original baked 2048-pixel wood/normal maps and all required
materials; no external network access is needed to display it. References were
used to model proportions, never as embedded product photographs or textures.

Original modeling source: `prototypes/tal1962/build.py` and
`scripts/sculpt_staunton_knight.py` (spline helper). To regenerate using Blender:

```powershell
blender -b -t 10 --python prototypes/tal1962/build.py -- --scene-only
blender -b -t 10 --python scripts/export_tal1962.py
```

The first script saves the sculpture and review scene under `prototypes/tal1962`.
The exporter bakes the original procedural materials and writes `ui/tal1962.glb`.
Only authored scripts and the runtime model ship; reference photographs,
studio renders and working Blender files are excluded from the package.

Historical-design reference: the seller's [1962 Soviet Championship
listing](https://www.etsy.com/listing/1845776566/1962-soviet-championship-historical).
This is Engine Arena's original modeled interpretation, not a scanned or
manufacturer-endorsed reproduction.

Pause and drain active games, then close Engine Arena before installing. This
update includes prior private changes. It does not require a new tournament.

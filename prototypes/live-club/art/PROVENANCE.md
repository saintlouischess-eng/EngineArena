# Club portrait references

`guest-face-atlas.png` and `levy-face.png` are generated cameo reference artwork
used by the project's character build scripts.

`younger-player-reference.png` is the photograph supplied by the owner on
2026-10-12 for the requested younger seated player's appearance. It is an
owner-supplied reference, not a MakeHuman CC0 asset or generated artwork. This
private update contains a fitted face/eye texture and original modeled hair
based on that reference; the result is an approximation from one view.

The MakeHuman base meshes, fitting data and graphical assets have their own
license and pinned source manifest in `vendor/MakeHuman/club-cast/`.
Original procedural grooming, shoe geometry, animation and room code are
project work. This document does not relicense the supplied photograph.

Engine Arena 1.10.3 - engine clock receipt correction

Includes the full 1.10 workflow update, fair round-robin replacement standings,
and the large-list Rating Center stability fix.

Engine replies are now timestamped by independent pipe readers. A delayed
application event loop no longer charges its processing delay to an engine that
has already replied. Actual late replies, silent-engine watchdogs, clock tolerance,
and pondering rules still apply. Stale telemetry is bounded without dropping
protocol replies. Delayed processing is recorded in diagnostic logs.

No historical game result or rating is changed by this update. Pause and drain,
close Engine Arena, install over the existing version, and resume when convenient.
See docs/V1_10_3_ENGINE_CLOCK_RECEIPTS.md for details and limitations.
